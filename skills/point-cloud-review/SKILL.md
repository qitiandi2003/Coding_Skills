# 从地图现象追溯采集和重建

在地图中标出问题区域和预期可辨认的结构，例如门框、门内的椅子或地面边缘。范围或视角未指定时，可按用户点名的对象选取局部区域，并在交付时交代所选范围和依据。如果几种解释会改变验收目标，且无法从现有材料判断，再请用户明确。保留原始地图与采集数据，在独立副本生成裁剪、过滤和网格预览，使前后版本能用相同视角比较。

先检查原始回波、对应时刻的位姿与 RGB，再看配准后的局部点云和最终渲染。图像投影对不上时检查时间、内外参和坐标系。区分单帧已有的回波、多帧叠加后出现的重影，以及生成网格才出现的封面或连边。仅有导出的地图时，说明尚缺哪些原始观测。

按用户关注的对象验收。判断家具几何时关闭颜色，从正面、侧面和斜角检查轮廓、空隙和遮挡关系。判断通行性时对照占据图、机器人所需净宽和实际障碍。报告局部对比，点数、面数和全局误差可作补充。

预览过滤仅能证明显示效果有变化。若要据此修改建图或导航输入，在相同录包上验证目标区域和邻近正常结构，并保留可恢复的原始产物。长时间处理要跟进到生成和对比都完成，遇到可恢复的失败就在授权范围内修正后重试。缺少原始数据或现场权限时，先做完已有材料支持的检查。

最终回复应能独立阅读。先说用户在哪个位置、从哪个角度会看到什么变化，再给出前后对比、采用的假设和未验证的部分。用可见现象解释技术结论，例如“从侧面可以看到椅背和墙之间的空隙”。将排查时的文件简称、区域代号和临时缩写换成读者能识别的名称。
