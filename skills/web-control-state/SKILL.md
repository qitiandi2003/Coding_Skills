# 验证控制台状态和操作

先列出一次操作产生的状态以及各自的所有者。需要跨端恢复的地图选择、任务草稿可由服务端保存，快照带版本供客户端处理迟到的响应。按键、摇杆输入和控制租约有独立生命周期；恢复画面时应走只读渲染路径。用请求记录确认刷新、重连和打开第二个客户端都没有发出控制指令。

单点导航在选点时可显示标明用途的参考路线，开始导航后切换到规划器给出的路线。切换地图或任务模式时，清除仅适用于上一模式的目标与预览，同时更新持久状态。通过刷新复查旧目标是否重新出现。

定位等耗时操作要让用户看到当前阶段、最近进展和终止原因。若后端支持操作标识，用它关联状态和日志，防止上一轮的完成事件覆盖本轮进度。

从桌面和手机分别走一遍选择、刷新、切换模式的路径，检查窄屏浮层是否挡住关键按钮。涉及静态资源发布时，从实际服务地址读取入口及其引用的资源，核对构建版本，并说明验证环境。
